This is a simple and responsive quiz application built using HTML, CSS, and JavaScript. Users can select answers to multiple-choice questions and get immediate feedback on their score once the quiz is submitted.

📌 Features
✅ Multiple choice questions

🎯 Score calculation and display

📱 Responsive design

✨ Clean and minimal UI

🔁 Easily extendable with more questions

🛠️ Technologies Used
HTML5 – Structure
CSS3 – Styling and layout

JavaScript – Logic and interactivity
